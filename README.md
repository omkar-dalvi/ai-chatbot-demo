# ai-chatbot-demo
Repo demonstrating a simple ai chatbot demo using openwebui and OpenAI models

- `uv add open-webui`
- `uv run open-webui serve`

> App will get hosted on http://localhost:8080

Download Ollama
- `irm https://ollama.com/install.ps1 | iex`

Download model
- `ollama run qwen3:0.6b`

Enjoy chatting!
